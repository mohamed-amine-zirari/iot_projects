# Operating Room IoT Project

IoT project for operating room monitoring using ESP32, MQTT, Node-RED, and sensors.

## Main parts
- ESP32 MicroPython code
- Node-RED dashboard flow
- Wokwi simulation
- Project document

## Folders
- `code/` ESP32 code
- `node_red/` Node-RED flow
- `wokwi/` simulation files
- `docs/` report and description
